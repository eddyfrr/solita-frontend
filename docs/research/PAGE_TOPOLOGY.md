# Page Topology — ayyahair.com

## Sections (top to bottom)

1. **Header** — Fixed top. Logo center, nav links below, search/wishlist/cart icons right. Mobile: hamburger + logo + cart.
2. **Hero Banner** — Full-width background image (Banner-main-1-scaled.jpg). Text overlay: "AYYA" heading, "LUXURY BRAIDING HAIR" subheading, "SHOP ALL" CTA button. Golden-toned image with woman.
3. **Featured Hair Section** — Heading "FEATURED HAIR" with product carousel/grid. Shows ~6 products with carousel dots on mobile, grid on desktop.
4. **Shop Catalog Section** — Recent products grid. 4-column desktop, 2-column mobile.
5. **Footer** — Olive/gold background (#b9a16b). Script logo, About Us text, Follow Us social icons (FB/IG/Pinterest), Newsletter form, bottom links bar with copyright.

## Interaction Model
- Header: Static (no scroll behavior changes)
- Hero: Static banner
- Products: Carousel on mobile (swipe/dots), grid on desktop
- Footer: Static
